<product_requirements>
The GuestWorker application tracks migrant worker attendance, wages, payments, and commissions. It requires a secure, responsive web app with FastAPI, React, and MongoDB. Core modules include Dashboard, Workers, Employers, a hybrid Attendance system, Payments, Reports, Account Management, and a public-facing website with subscription plans. Security features like JWT in HttpOnly cookies and HTTPS are paramount. The application targets non-tech-savvy users, emphasizing intuitive UX.

A new, comprehensive **Admin Panel** is being developed. It requires secure, role-based access (Super Admin, Sub Admin) and a separate login. The panel will manage users (contractors, employers, workers), subscription plans, activation/coupon codes, detailed financial and usage analytics, system settings, backups, and support requests. Key features for Phase 1 include Admin Authentication, a Basic Admin Dashboard (with key analytics), and User Management (listing contractors, viewing profiles, basic account actions).
</product_requirements>
